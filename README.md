# Innova Campo y Jardín — sitio para GitHub Pages

Este proyecto es una página web estática basada en la presentación proporcionada de Innova Campo y Jardín S. de R.L. de C.V.

## Archivos
- `index.html` — estructura y contenido de la página.
- `styles.css` — diseño responsive.
- `script.js` — menú móvil y año automático.
- `assets/` — imágenes tomadas de la presentación.

## Publicarla gratis en GitHub Pages
1. Entra a GitHub y crea un repositorio, por ejemplo: `innova-campo-jardin`.
2. Sube `index.html`, `styles.css`, `script.js` y la carpeta `assets`.
3. En el repositorio ve a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, guarda.
6. GitHub te mostrará la dirección de tu sitio.
7. Para usar tu dominio propio, en GitHub Pages agrega tu dominio en **Custom domain**.

## Dominio de Hostinger
El dominio puede seguir registrado en Hostinger. Lo que cambia es el alojamiento: el sitio se sirve desde GitHub Pages.

Para configurar DNS con seguridad, primero dime tu dominio exacto (por ejemplo `midominio.com`) y te indico qué registros debes poner en Hostinger según tu dominio y si quieres usar `www` o el dominio sin `www`.

## Nota
El enlace de Facebook de la presentación solo indica “Agro Supply”; por eso el proyecto deja un enlace genérico de Facebook. Sustitúyelo por la URL exacta de la página de Facebook de la empresa cuando la tengas.
